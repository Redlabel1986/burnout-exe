# burnout.exe

One-page site for the electronic project **Burnout.exe** and the album
_Neon Stack Overflow_. Built with Vite + React + TypeScript.

## Dev

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy (Vercel)

The repo ships with `vercel.json` configured for Vite. Import the repo on
[vercel.com](https://vercel.com/new) — no extra settings required.

- Framework preset: Vite
- Build command: `npm run build`
- Output directory: `dist`
- Production domain: `burnout-exe.dev`
